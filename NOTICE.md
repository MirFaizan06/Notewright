# Third-party material

## Salamander Grand Piano V2

- What: 30 MP3 recordings of a Yamaha C5 grand piano (every third key, A0 to C8, one velocity layer), in `web/assets/piano/`.
- Author: Alexander Holm.
- Licence: [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
- Source: the compact set in the Tone.js audio repository, <https://github.com/Tonejs/audio/tree/master/salamander>. The files are used unmodified, only for the in-app MIDI preview. The original readme is kept as `web/assets/piano/SOURCE-README.txt`.

The credit is also shown in the app's About dialog. If you redistribute Notewright, keep this notice.
